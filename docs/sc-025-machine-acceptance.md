# SC-025 Windows 实机验收

本清单验收实际安装的最新候选包。自动化测试、开发预览和旧安装包不能代替系统结果。每项记录日期、安装包 SHA-256、操作、实际结果；尚未操作保持未验收。

## 准备

使用专门的 Windows 测试账户，避免导入、卸载或修改自己的日历。安装包位于仓库的 `apps/desktop/src-tauri/target/release/bundle/nsis/Semantic Calendar_0.1.0_x64-setup.exe`；最新指纹和已执行项目见 [release.md](release.md)。启用 Windows 通知并暂时关闭勿扰，应用设置中打开日历提醒。

在仓库根目录运行下面命令，立即导入输出的 ICS 路径，把比赛提醒设为“提前 10 分钟”。脚本显示两条通知的本机预期时间，普通通知约 3 分钟后、比赛通知约 6 分钟后；若导入不及时，重新生成一份。脚本只生成测试文件。

```powershell
powershell -File apps/desktop/tools/create-acceptance-ics.ps1
```

## 逐项验收

| 项目 | 操作 | 通过条件 |
| --- | --- | --- |
| 安装向导 | 运行最新安装包，选择中文；逐页检查许可、安装路径、完成页，从开始菜单启动 | 名称、版本、许可和路径正确，能够启动；记录实际出现的页面，模板跳过的页面记为不适用 |
| 日期详情 | 导入测试日历，选中事件日期，再连续切换两个月；返回并改选、关闭/开启测试来源 | 网格外的已选日期详情不丢失，普通事件和比赛详情正确；来源关闭后事件消失、开启后恢复 |
| 主题与窗口 | 明暗主题各切一次，缩到最小尺寸，再恢复 | 日期、比赛、详情和操作入口可读，没有遮挡或错误空白 |
| 托盘与单实例 | 将关闭行为设为隐藏，点窗口关闭；左键托盘、右键“显示”；再启动一次应用；右键退出；最后验证关闭行为“退出” | 隐藏后仍常驻，各恢复入口只有一个可操作窗口，退出后进程消失 |
| 普通和比赛通知 | 等脚本给出的两次时间，第二次等待期间隐藏到托盘 | Windows 系统各出现一条对应通知，标题/内容正确，比赛仍显示比赛语义；应用内状态可解释 |
| 重启去重 | 第一条通知后立即真正退出再启动，第二条后也重启；保持同一来源、同一 UID | 同一条已发送通知不重复；重启仍能收到未到期的第二条。不要重新导入成新来源来测去重 |
| 真实 WebCal | 添加有权限使用的专门远程验收订阅，刷新；在服务端改事件，再刷新；断网刷新后恢复联网；删除测试来源后重启 | 200 更新正确；失败有说明且保留缓存；删除后不恢复。服务支持 ETag/Last-Modified 时用服务日志确认第二次未改动刷新确为 304；不支持则 304 项保持未验收 |
| 取消和删除 | 用专门的大/慢订阅触发刷新，在“刷新中”删除，等待旧请求可能完成的时间后重启；同 URL 重加一次 | 删除来源及旧事件不恢复；重加来源只显示新请求的数据，不被旧请求覆盖。无需删除自己的订阅 |
| 休眠恢复 | 新生成测试日历；在普通通知时间前休眠，通知时间后 1 分钟内唤醒；长休眠一轮用同一脚本加 `-MatchDelayMinutes 150` 生成日历，在普通通知时间之前休眠、约 125 分钟后唤醒（比赛提醒仍未到期） | 短延迟普通通知只补一次；超过 2 小时容忍窗口的旧提醒不补发，后续比赛提醒仍正常。检查应用状态和系统通知中心 |
| 自然跨午夜 | 在本地午夜前选中一日期、切到另一月份，保持应用运行；午夜后恢复窗口，再点“今天” | 恢复后今天标记为新日期，保留原选择和视图；点今天才跳到当前月和新日期。优先自然跨天，不修改自己的系统时间 |
| 升级保留 | 在测试账户安装旧包并导入日历，发送第一条后退出；覆盖安装最新包，再启动；使用第二轮日历检查未来提醒 | 来源、事件、设置和已发送记录保留；旧通知不重复，新提醒能触发。旧包的指纹也必须记录；缺旧包则此项未验收 |
| 卸载保留 | 真正退出，卸载；检查快捷方式和安装目录；再装最新包启动 | 程序和快捷方式移除，测试账户数据快照保留；重装后来源/设置仍可读且已发通知不重复 |

## 记录和关闭条件

普通/比赛通知必须实际出现在 Windows；“已发送”状态只表示调用成功，不能作为看到 Toast 的证据。没有 304 服务证据时，不将一次成功刷新写成 304 通过。休眠、升级和自然跨天分别记录，不能用重启代替。

记录模板：`项目｜时间｜包 SHA-256｜输入/操作｜预期｜实际｜通过/失败/未验收｜截图或日志位置`。如失败，保留最短复现步骤及脱敏日志。

所有必需项通过后才能关闭 SC-025 和 V0.1 收尾；一项未验收即保留工单，已经通过的自动化和实机项目不用无故重做。
