# 界面细节与设置切换修复记录

日期：2026-09-27

## 界面细节

- 左右栏的折叠按钮移到顶部，保留按钮的可访问名称、提示和展开状态。右栏底部不再为按钮预留独立区域，比赛日背景可铺到底部。
- 左栏底部仅保留设置入口和状态说明，增加分隔与间距，消除两个按钮夹着状态文字的布局。
- 内置日历与导入日历统一显示颜色方块。内置日历使用固定语义色，导入来源按 ID 从八色调色板派生颜色，重新渲染不会随机换色；扩展调色板后部分已有导入来源的颜色会改变一次。
- 比赛格内的普通日程摘要保留，去掉左侧强调条。截图中的「02:32 SC…」是独立普通事件，并不是比赛的重复提示。
- 比赛详情的开赛、场地与提醒行增加图标、分隔线和间距。场地仍只展示赛程实际提供的 LOCATION；天气尚未接入，不补造数据。队徽仍沿用原有资源缺失时的缩写回退。

## 设置打开时的布局抖动

设置打开时立即替换月历，并同时隐藏详情栏；原三栏骨架仍以 200 毫秒动画改变栏宽，导致新设置页面在过渡期间持续重新布局，可能跨越容器断点并重新换行。这是与用户反馈吻合的代码原因，尚未通过实际画面复现确认。

移除骨架的栏宽过渡，让页面与栏宽同时到位；设置页仅使用 140 毫秒透明度淡入，不动画改变尺寸或位置。系统开启减少动态效果时关闭淡入动画。返回月历和手动折叠两侧栏也不再播放栏宽过渡。

新增布局稳定性回归检查，修复前因检测到 `grid-template-columns 200ms ease` 失败，修复后通过。
